Module 1 Fundamentals

Data vs. Information

Core foundational concepts for BSCS and BSIS students.

What is Data?

Data consists of raw, unorganized, and unprocessed facts, figures, symbols, or observations. By itself, data lacks context, meaning, or intent. In computer science, data can be numbers, text, audio, or video stored in databases or files.

Examples of Raw Data:
  • 50000, 35000, 20000
  • "Maria Santos", "M'lang, Cotabato"
  • 101, 92, 88 (Unlabeled student exam scores)

What is Information?

Information is data that has been processed, structured, contextualized, and organized to make it meaningful and useful for decision-making. Information answers questions like "who," "what," "where," and "why."

Processed Information:
  • Sweet Crumbs Bakery generated a monthly net profit of ₱15,000 in M'lang, Cotabato.
  • Class average score in Data Structures is 93.6% (passing rate 98%).

Key Differences at a Glance

Feature Data Information
Definition Raw, unorganized facts Processed, structured data
Dependency Does not depend on information Depends entirely on data
Meaning Meaningless on its own Has context and meaning
Usage Input for information systems Used for decision making
Module 2 Architecture

The Information Processing Cycle

How computer systems transform raw inputs into actionable intelligence.

01

Input

Entering raw data into the system via keyboards, scanners, forms, or APIs.

02

Processing

CPU and algorithms execute calculations, sorting, and filtering on the raw input.

03

Output

Displaying processed information on screens, reports, or dashboards for users.

04

Storage

Saving data and information onto databases or cloud servers for future retrieval.

05

Feedback

User reactions or system logs used to verify accuracy and refine future processing.

Computing Connection: Information Systems

For BSIS and BSCS students, understanding this cycle is paramount. An Information System (IS) automates this entire loop across enterprise networks. For instance, in a Point-of-Sale (POS) system, scanning a barcode (Input) queries inventory databases (Storage), computes total sales and taxes (Processing), prints receipts or dashboard charts (Output), and records transaction metrics for auditing (Feedback).

Module 4 Ethics & Security

Responsible Data Use

Essential data protection, privacy, and integrity principles for computing professionals.

Data Privacy

Safeguarding personally identifiable information (PII) against unauthorized access. IT systems must comply with regulations like the Data Privacy Act to protect user confidentiality.

Data Security

Implementing robust encryption, secure authentication, firewalls, and secure database practices to prevent cyber threats and data breaches.

Ethical Collection

Obtaining informed consent before collecting user data. Developers must collect only necessary data and ensure transparency on how information is processed.

Data Integrity

Ensuring accuracy, consistency, and reliability of data throughout its lifecycle in information systems. Garbage in results in garbage out (GIGO).
